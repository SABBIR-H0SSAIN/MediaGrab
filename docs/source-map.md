## Extension boundaries

New media platforms implement [BaseExtractor](../lib/features/extractor/data/extractors/base_extractor.dart) and register with `ExtractorFactory`. Return genuine streams and pass companion audio through the existing manager and engine. Add platform URL detection and source-specific fixtures where required. Every playlist/multi-URL enqueue uses `enqueueBatchMediaDownloads`. Shared merging belongs in `MediaMerger`, not a new platform-specific FFmpeg pipeline.

New completed-media consumers read `DownloadRegistry`. New persistence fields need compatibility with existing records and fixtures for old formats. Keep the existing provider patterns, routes, IDs, and selected-format semantics unless the task explicitly requires a reviewed change.
